# Research Assistant Frontend

Next.js dashboard for submitting research jobs, tracking progress, opening cached reports, and viewing backend metrics.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

By default the UI calls the backend at `http://localhost:3001`. Override it with:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:3001
```

## Scripts

npm run dev
npm run lint
